# NexusFlows

NexusFlows is a workflow automation app for building, scheduling, and running automated flows.

## Getting Started

Run the development server:

```bash
npm run dev
```

Or run Next.js and the Inngest dev server together:

```bash
npm run mprocs
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

- `npm run dev` — start Next.js on port 3000
- `npm run inngest:dev` — start the Inngest dev server
- `npm run mprocs` — run both dev processes together
- `npm run build` — production build
- `npm run start` — start production server
